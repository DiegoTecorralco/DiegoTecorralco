# 🚀 Proyectos que he desarrollado

## 🎓 Sistema Web de Control de Asistencia Escolar

Aplicación Full Stack desarrollada con React + TypeScript (frontend), Node.js + Express (backend) y MongoDB (base de datos).

### Funcionalidades implementadas:

- Registro de asistencia mediante NIA.
- Búsqueda automática del estudiante en la base de datos.
- Registro de grupo y control en colección separada.
- Autenticación con JWT.
- Middleware de verificación de token.
- Cierre automático de sesión al expirar token.
- Bitácora con filtros por fecha y grupo.
- Edición y eliminación de registros con modales.
- Validaciones completas frontend/backend.
- Pruebas unitarias con Jest.
- Pruebas de integración con Postman.
- Arquitectura modular profesional.
- Preparado para despliegue en Vercel o Hostinger.
